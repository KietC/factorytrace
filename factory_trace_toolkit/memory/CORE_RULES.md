# Core reusable rules

## English

These rules define evidence semantics, preservation, independence and review boundaries. Reuse the workflow, not historical company conclusions. A product image or certificate holder is a lead unless exact entity/site/SKU/process scope closes. Atomic file integrity does not establish authenticity. Region and procurement utility remain separate from attribution. Models propose hypotheses but do not become source evidence. Maintain explicit unresolved states, counterevidence and review triggers.

For ordered cross-platform commands, expected outputs and recovery actions, use [DEPLOY.md](../../DEPLOY.md). The Chinese reference below retains the full method details; command names and schemas are language-independent.

# 通用核心记忆

1. 把销售/合同/收款、制造责任法人、实际地点、精确SKU/批次和目标工序分开。
2. 把角色、部件、地点/工序组成明确Claim；“某公司是厂家”不合格。
3. 同图、商标、店铺、最早网页、专利、持证人和shipper只能发现线索。
4. 商标被声明无关时，工厂归因计零，只用于传播链。
5. “未检出公开资料”不等于“不存在”或“不生产”。
6. 开模、盘体深拉、阀头制造、装配、测试和包装可能属于不同主体。
7. 同源转载只算一个independence group；反证不能被重复营销材料覆盖。
8. 原件先冻结并哈希；所有裁剪、遮挡、OCR和增强保留lineage。
9. 有设备只证明能力线索，必须继续绑定准确地点、目标SKU/批次和目标工序。
10. AI和相似度算法只生成候选，不能直接成为制造关系证据。
11. 所有链接、联系方式、证书和状态记录来源、UTC、本地副本和最后核验时间。
12. ESS不是统计概率；没有校准样本时不输出伪精确的厂家概率。
13. confirmed必须通过最新审计，且存在独立直接证据、反证审查和批次/地点/工序闭环。
14. 当前状态覆盖旧报告；历史错误保留为superseded，不得删除后继续误用。
15. 并行泳道各自写结果，由单一Reconciler合并canonical真值。
