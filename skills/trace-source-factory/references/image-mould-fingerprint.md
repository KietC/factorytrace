# Images, Structure, and Tooling Fingerprints

## English

### Image/material intake

Request front/back/underside/sides/oblique views; disassembled critical parts/interfaces; ruler/caliper dimensions, spacing, bore, thickness, and height; plates/laser codes/hidden marks/batch/pack labels; and continuous tooling/equipment/material-to-product video. Compare several pieces from one batch so an incidental defect is not mistaken for a tooling feature.

A trademark does not identify the supplier by default. Preserve the original, then derive logo-neutral, grayscale, crop, mirror, and contour views as needed, recording parent hash and transformation parameters. External image-search submission requires authorization, especially for confidential images/drawings.

### Fingerprint features

Choose product-relevant features: inner/outer radii, draft, parting/ejector marks; flange/rolled-edge section, trimmed shape, hole coordinates; ribs/bosses/grooves/curvature; drawing/flow/cutter/polish/weld/burr marks; hole count/diameter/pitch, threads, steps, and sealing surfaces; and code font/spacing/position.

Shared-tooling attribution requires multiple features difficult to explain by marketing dimensions alone. Same shape and nominal size establish family/compatibility at most, not the same mould.

### Image comparison

Correct perspective and scale before contour overlays, keypoint distances, normalized pixel differences, or edge comparisons. Record algorithm, thresholds, input hashes, and manual review. Compression, camera angle, mirroring, and background removal can cause false differences or similarities. A pixel metric is a screening tool, not a factory probability.

### Physical closure and conclusion levels

Obtain same-specification samples or high-resolution hidden-surface images from serious candidates. Measure hidden dimensions, mass, material, hardness, wall thickness, and hole positions. Use appropriate PMI/XRF, metallography, or section examination when justified; tests must bind sample ID, batch, and custody/sealing chain.

- `visual_family_match`: same appearance family.
- `structural_match`: multiple structural/dimensional matches.
- `probable_shared_tooling`: difficult-to-copy fingerprints align and common open tooling is excluded.
- `confirmed_shared_tooling`: tooling ID, drawings, trials/production records, or site evidence close the claim.

These labels describe evidence scope; do not convert image similarity into manufacturer probability.

## 中文

# 图片、结构与模具指纹

## 索取照片

至少请求：

- 正面、背面、底面、两侧和 45 度视角。
- 拆件后的关键零件和接口。
- 带标尺或卡尺的总尺寸、孔距、口径、厚度和高度。
- 铭牌、激光码、暗记、批次码和包装标签。
- 模具、夹具、设备、原料到成品的连续视频。
- 同一批次多件产品，避免把偶然瑕疵当模具特征。

商标默认与供应商无关；先保留原图，再生成无商标、灰度、局部、镜像和轮廓版本。每个派生图必须记录父文件和变换参数。

图片提交外部识图服务须符合授权，尤其是保密照片和图纸。

## 模具指纹

按产品类型记录：

- 内外圆角半径、拔模斜度、分型线和顶针位置。
- 翻边宽度、卷边截面、修边形状和冲孔中心坐标。
- 筋位、凸点、加强结构、凹槽和局部曲率。
- 拉伸纹、流痕、刀痕、抛光方向、焊缝和毛刺。
- 孔数、孔径、孔距、螺纹、接口台阶和密封面。
- 激光码字体、字符间距和定位基准。

同模判断应基于多个难以由营销尺寸解释的特征。仅外形和标称尺寸相同最多支持“同类/兼容”，不能证明同模。

## 像素比对

先校正透视和尺度，再做轮廓叠加、关键点距离、归一化像素差和边缘相似度。记录算法、阈值、输入哈希和人工复核结果。平台压缩、拍摄角度、镜像和后期抠图会制造假差异或假相似。

## 物理样品闭环

在高价值候选间获取同规格样品或底面高清图，测量隐藏尺寸、重量、材料、硬度、壁厚和孔位。必要时使用 XRF/PMI、金相或截面检查。检测报告必须绑定样品 ID、批次和封样链。

## 结论边界

- `visual_family_match`：同类外观。
- `structural_match`：多个结构和尺寸吻合。
- `probable_shared_tooling`：难仿模具指纹高度吻合且排除常见公模。
- `confirmed_shared_tooling`：模具编号、图纸、试模/生产记录或现场证据闭合。

不要把图片相似度数值直接换算成厂家概率。
