# Deprecated patterns

## English

Do not use manually entered grades or percentages as a manufacturer truth source. Do not count reposts as independent evidence, equate exporters/licence holders/assemblers with tooling factories, or infer factory ownership from an image match. Keep deprecated compatibility fields out of public probability claims. Replace old narrative conclusions with fresh canonical evidence and audits; retain old originals for history without importing them into new cases.

For ordered cross-platform commands, expected outputs and recovery actions, use [DEPLOY.md](../../DEPLOY.md). The Chinese reference below retains the full method details; command names and schemas are language-independent.

## 中文详细参考

# 失效规则与禁止迁移项

以下旧做法永久停用：

- `同款图 -> 店铺 -> 厂家`
- `Licence Holder = Manufacturer`
- `Shipper/Exporter = Producer`
- `有同类设备 = 生产目标SKU`
- `官网没展示 = 不生产`
- `最早被搜索引擎抓到 = 原创/首发`
- `多个转载URL = 多个独立证据`
- `人工填写A/5/5或百分比 = 审计通过`
- `operational PASS = 厂家已确认`
- `模型回答或视觉相似分数 = 制造证据`
- 并行代理直接共同改同一candidate/manifest/ledger

历史文件如包含上述结论，必须标记`superseded`并重新迁移、重算、重审。
